# OIBSIP-Project
Billing System Using Python Tkinter

A simple and user-friendly Billing Management System developed using Python and Tkinter. This desktop application is designed for shops and small businesses to manage billing operations, store billing-related data, and generate customer bills efficiently.

🚀 Features

- Simple and interactive Graphical User Interface (GUI).
- Store and manage billing information.
- Generate customer bills.
- Easy-to-use billing interface.
- Reduces manual billing work.

🛠️ Technologies Used

- Python
- Tkinter
- OS Module
- MessageBox

▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the "billing system.py" file.
4. Start using the billing application.

🎯 Project Objective

The main objective of this project is to simplify shop billing operations, reduce manual effort, and provide an easy way to generate customer bills.

👨‍💻 Developer

Developed as a Python GUI-based project for practical application and learning.

## Billing Software – Project Screenshot

![Billing Software Screenshot](Bill.PNG)


🧾 Billing Software

A Python-based desktop Billing Software application developed using Tkinter GUI. This application helps shops manage customer billing, calculate product prices, apply taxes, and generate bills quickly and efficiently.

📸 Project Screenshot

"Billing Software Screenshot" (Bill.PNG)

✨ Features

- Customer Details: Enter customer name, phone number, and bill number.
- Product Management: Select products from different categories.
- Medical Products: Sanitizer, Mask, Hand Gloves, Syrup, Cream, and Thermal Gun.
- Grocery Items: Rice, Food Oil, Wheat, Spices, Flour, and Maggi.
- Cold Drinks: Sprite, Mineral Water, Juice, Coke, Lassi, and Mountain Dew.
- Automatic Calculation: Calculate product totals and final billing amounts.
- Tax Calculation: Apply medical, grocery, and cold-drink taxes.
- Bill Generation: Generate and display customer bills.
- Bill Search: Search for customer bills using bill details.
- Clear & Exit: Clear entered information and close the application.

🛠️ Technologies Used

- Python
- Tkinter (GUI)
- OS Module
- Messagebox
